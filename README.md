This Playwright automation project demonstrates UI test automation skills using JavaScript. The project covers e-commerce user journeys. The project is built using the Page Object Model (POM) design pattern. It was created as part of my personal learning portfolio.

The technologies used:
-Playwright
-JavaScript
-Node.js
-Git

Test scenarios:
-valid login 
-invalid login
-add product to cart
-remove product from cart

Project structure:
tests/		#test cases
pages/		#Page Object Model (POM) classes
playwright.config.js
package.json
README.md

How to run tests:

npx playwright test ./tests/ (include --headed to run in headed mode)
